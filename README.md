# 昕启·朔元 · 分发仓

本仓**只放安装包与更新清单**；源码不在公开范围。

## 安装

下载 `xin-qi-shuo-yuan-<版本>-setup.exe` 运行。安装器可选安装目录，装完桌面有快捷方式。

## 更新

桌面端「设置 › 通用 › 桌面 › 应用更新」有版本与检查入口。检查更新读的是本仓 Release 里的
`latest.yml`（版本号、安装包地址、sha512、体积），客户端据此判断有没有新版本。

## 资产构成

每个 Release 对应一个版本号（tag `v<版本>`），固定三件：

| 资产 | 用途 |
|---|---|
| `xin-qi-shuo-yuan-<版本>-setup.exe` | 安装包（NSIS） |
| `xin-qi-shuo-yuan-<版本>-setup.exe.blockmap` | 增量下载用的分块对照 |
| `latest.yml` | 更新清单：客户端只认这一份 |

## 注意

安装包内不含任何模型密钥与会话数据 —— 那是每台机器首次运行时自己配的。
